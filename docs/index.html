Two Tools, One Repository

Internet Scanners Extractor

Extract and enrich IP addresses from known internet scanning projects.

  • IPv4/IPv6 detection from text files
  • Reverse DNS (PTR) lookups
  • ASN enrichment via IPWhois
  • AbuseIPDB reputation (optional)
  • Multithreaded processing
  • JSON + CSV timestamped exports
CLI GUI

Reverse MX Lookup Tool

Analyze email infrastructure and discover domains sharing mail servers.

  • MX record lookups
  • Reverse MX via ViewDNS, DomainTools, WhoisXML
  • Single target or batch file input
  • CSV export of results
  • API key management
  • Configurable throttling
CLI GUI

Quick Start

git clone https://github.com/mo0ogly/Internet-Scanners-OSINT-Tool.git
cd Internet-Scanners-OSINT-Tool
pip install -r requirements.txt

# Internet Scanner
python3 internet_scanner.py

# Reverse MX Lookup
python3 cli_Reverse_MX_Lookup_Tool.py --mode mx_lookup --target example.com

# GUI versions
python3 gui_scanner.py
python3 gui_Reverse_MX_Lookup_Tool.py
